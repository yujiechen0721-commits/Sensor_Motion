即時辨識

手機上的 Sensor Logger 持續把加速度計與陀螺儀資料傳到這個網站，網站每 2.5 秒更新一次判斷。

判斷紀錄（最近約 3 分鐘，每格一個視窗）

捷運公車汽車

手機端設定（Sensor Logger）

  1. 電腦與手機連到同一個 Wi-Fi，並用 $env:HOST="0.0.0.0"; $env:PORT=5055; python web/app.py 啟動網站（PowerShell）。
  2. Sensor Logger → Settings → Data Streaming → 開啟 Push to HTTP，網址填：載入中…
  3. Sensor Logger 的感測器只勾 Accelerometer 與 Gyroscope，按 Start Recording。
  4. 開始後前 30 秒不辨識（排除上車的動作），約 40 秒後會出現第一個判斷，之後越穩定。

如果 Windows 跳出防火牆詢問，請允許 Python 使用「私人網路」。

沒有手機時：示範回放

用測試集的一筆錄製，模擬成即時資料送進來（這些錄製沒有參與訓練）。

即時模式的限制

  • 只看「過去」的資料來判斷，剛開始的準確度比較低；越久越穩定。
  • 模型沒看過的手機、放置位置或路線，結果可能不準（參考「模型成效」頁）。
  • 網站只在記憶體暫存，關掉網站資料就沒了。
